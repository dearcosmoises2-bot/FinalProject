**Start Objective**

The starting objective of this project is to establish the project topic, define the purpose of the system, and organize the repository for the required final project deliverables.

The selected topic is the Landfill e-Forms Application. The purpose of the project is to design a system that replaces a paper-based landfill methane-emission auditing workflow with a digital workflow.

**The project includes two major system components:**
- A mobile application for field inspectors to collect inspection data
- A web application for uploading, reviewing, managing, and storing submitted records

The initial goal is to organize the repository and begin development of the required project deliverables, including the README, Software Requirements Specification, Software Design Document, Design Specification, TestRail documents, and Workflow Diagram.
